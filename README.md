# Cosy Seasons

A cosy animated backdrop for the Claude desktop and mobile apps that follows the calendar: a snowy night with a Christmas tree, an A-frame cabin and three friends (a girl, a frog and Kuro the black cat) in winter, cherry petals in spring, fireflies over a meadow in summer, and drifting leaves in autumn.

The ground pile (snow, petals, meadow grass or leaves) rises with your context window fill, and a seasonal marker on the right (a snow pole, bamboo cane, sunflower or fence post) marks each quarter of the window. Compacting the conversation melts it back down.

`/season auto|winter|spring|summer|autumn` picks a season; `/season south` flips the calendar for the southern hemisphere.

## Install

```
/plugin marketplace add Qibbles/cosy-seasons
/plugin install cosy-seasons@cosy-seasons
```

The backdrop draws in the Claude desktop and mobile apps; terminals and editors show none.
